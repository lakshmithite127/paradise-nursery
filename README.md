# Paradise Nursery Shopping Application

A dynamic e-commerce web application built with React and Redux Toolkit that allows users to browse houseplants across multiple categories, view plant details, manage a shopping cart, and calculate totals dynamically.

## Features
- Landing page with background styling and "Get Started" call to action.
- Navigation bar linking Home, Plants, and Cart with a live cart item counter.
- Product listing categorized into 3+ groups with at least 6 plants per category.
- Interactive "Add to Cart" functionality that disables upon adding.
- Fully interactive Shopping Cart page with quantity adjustments, item removal, cost calculations, and checkout.
